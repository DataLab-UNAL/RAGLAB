Paso 1 · prepara tu espacio de trabajo

Tu proyecto, con historial y respaldo

En este curso usaremos Git para guardar el historial de cambios del proyecto en el computador y GitHub para almacenar una copia en línea del repositorio. Esto permite que cada estudiante tenga respaldo, control de versiones y un espacio claro donde entregar sus avances.

En línea

GitHub

Guarda el repositorio en línea, aloja el fork personal y permite sincronizar los cambios del estudiante.

  2. 02Confirma tu correo y completa tu perfil básico.
  3. 03Instala Git desde git-scm.com/downloads.
  4. 04Abre una terminal y configura tu nombre y correo.

¿Dónde ocurre cada parte? Crea la cuenta en el navegador y ejecuta los comandos en una terminal de tu computador: PowerShell o Git Bash en Windows, o Terminal en macOS y Linux.

Paso 7 · Programación asistida por agentes

Kiro en PyCharm: del requerimiento al código que podemos validar

¿Qué es Kiro?

Kiro es un agente de programación con inteligencia artificial. Puede leer el contexto del proyecto, explicar código, proponer y editar archivos, y ejecutar comandos. Usaremos Kiro CLI junto con el plugin Kiro with GUI para trabajar desde un panel dentro de PyCharm.

En este ejercicio te ayudará a convertir una necesidad en un cambio pequeño y comprobable. Tú decides qué pedir, revisas el plan y el diff, y ejecutas el programa para validar el resultado.

Instalación y configuración

Prepara el CLI y agrega Kiro with GUI a PyCharm

Sigue este orden: instala y autentica Kiro CLI, instala el plugin y comprueba que el panel de Kiro aparezca en el IDE.

01
Preparación

Instala y autentica Kiro CLI

  1. Abre la página oficial de instalación, cambia de la pestaña IDE a CLI y descarga Kiro CLI para tu sistema. No instales Kiro IDE.
  2. En Windows, instala la versión para Windows 11. Abre PowerShell y comprueba el CLI con kiro-cli --version.
  3. Inicia sesión con kiro-cli login y completa la autenticación en el navegador.
  4. Confirma que todo esté listo con kiro-cli doctor.
02
Plugin de PyCharm

Instala Kiro with GUI

En PyCharm, abre File → Settings → Plugins → Marketplace, busca Kiro with GUI e instala el plugin. Si aparece el aviso de plugins de terceros, selecciona Accept. Reinicia PyCharm si lo solicita.

03
Configuración

Verifica el CLI desde el panel de Kiro

  1. Abre Kiro desde el icono morado que aparece en la barra lateral de PyCharm.
  2. En el panel de Kiro, abre Manage → Settings (o Settings → Tools → Kiro) y verifica el campo del comando de Kiro.
  3. Si kiro-cli no se detecta, reemplázalo por la ruta completa. En Windows puedes encontrarla en PowerShell con Get-Command kiro-cli | Select-Object -ExpandProperty Source.
  4. Comprueba en Manage → Auth que la sesión esté iniciada. Si no, ejecuta kiro-cli login en PowerShell y vuelve al panel.
Práctica guiada

Pide, revisa, ejecuta y valida

Abre modulo-01/ejercicios/04_funciones.py y envía este requerimiento a Kiro:

Requerimiento para Kiro

En modulo-01/ejercicios/04_funciones.py, agrega una función llamada calcular_progreso(completados, total) que retorne el porcentaje completado como un número entre 0 y 100. Si total es 0, debe retornar 0. Agrega ejemplos de uso al final del archivo. No edites otros archivos. Antes de cambiar el código, explícame el plan y espera mi aprobación. Después de implementar, dime cómo comprobar los resultados.
  1. 01
    Lee el plan

    Verifica que Kiro entendió el archivo, la fórmula y el caso total = 0.

  2. 02
    Inspecciona el diff

    Ubica la función, sus argumentos, el valor que retorna y el caso especial.

  3. 03
    Ejecuta y comprueba

    Verifica que 2 de 4 produzca 50 y que el caso con total 0 produzca 0.

  4. 04
    Guarda cuando lo entiendas

    Si algo falla, comparte el error con Kiro. Cuando la mejora funcione, revisa git diff, crea un commit y súbelo a GitHub desde la rama DEV.

Soporte

Si algo se detiene, retoma desde el paso correspondiente

Busca el síntoma y vuelve a la sección indicada. Así podrás resolverlo sin repetir toda la configuración.

Miniconda · Paso 3

conda no se reconoce

En Windows, abre Anaconda Prompt desde Inicio; el instalador recomienda dejar desmarcada la opción para agregar Conda al PATH. En macOS o Linux, abre una terminal nueva después de instalar.

PyCharm · Paso 4

No aparece tu fork al clonar

En Settings → Version Control → GitHub, confirma que PyCharm inició sesión con la cuenta que contiene tu fork de RAGLAB. Luego vuelve a Clone Repository y selecciona ese repositorio.

Entorno · Paso 4

PyCharm no encuentra Python

En la configuración del intérprete, agrega un intérprete Conda existente y selecciona el entorno RAGLAB. Si aún no existe, créalo desde la carpeta raíz con conda env create -f RAGLAB.yml y luego actívalo con conda activate RAGLAB.

Kiro · Paso 7

Kiro no aparece en PyCharm

Confirma que Kiro with GUI figure como instalado en Settings → Plugins → Installed. Reinicia PyCharm y comprueba que el comando del CLI esté configurado en Manage → Settings.

Git · Paso 6

El commit o Push falla

Revisa git status y confirma que estás en la rama DEV. Si Git solicita identidad, configura el nombre y el correo asociados a tu cuenta de GitHub; después vuelve a intentar el commit y git push origin DEV.

Instalación · Pasos 3 y 4

La creación del entorno demora

La primera instalación descarga dependencias como torch y transformers. Mantén abierta la terminal y espera a que termine; si aparece un error, comparte el primer mensaje de fallo antes de volver a ejecutar el comando.

Para pedir ayuda

Comparte el contexto del error

Indica el paso que seguías, qué esperabas que ocurriera y qué ocurrió. Copia el mensaje completo de la terminal o adjunta una captura donde se vea la ventana relevante.
