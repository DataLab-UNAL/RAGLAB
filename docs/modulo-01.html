En este curso usaremos Git para guardar el historial de cambios del proyecto en el computador y GitHub para almacenar una copia en línea del repositorio. Esto permite que cada estudiante tenga respaldo, control de versiones y un espacio claro donde entregar sus avances.

Paso 7 · Programación asistida por agentes

Kiro en PyCharm: del requerimiento al código que podemos validar

¿Qué es Kiro?

Kiro es un agente de programación con inteligencia artificial. Puede leer el contexto del proyecto, explicar código, proponer y editar archivos, y ejecutar comandos. Lo conectaremos a PyCharm para pedirle una mejora desde el chat, como si trabajaras con un asistente que conoce los archivos abiertos.

En este ejercicio te ayudará a convertir una necesidad en un cambio pequeño y comprobable. Tú decides qué pedir, revisas el plan y el diff, y ejecutas el programa para validar el resultado.

¿Cómo llega a PyCharm? Kiro CLI se conecta mediante Agent Client Protocol (ACP), un protocolo que permite usar agentes externos desde el chat de AI Assistant.

Antes de conectarlo

Prepara estas herramientas

IDE
PyCharm y AI Assistant

Usa PyCharm 2025.3.2 o posterior. Si AI Chat muestra el botón Install Plugin, instala primero AI Assistant y reinicia PyCharm si te lo pide. Para usar un agente ACP no necesitas una suscripción de JetBrains AI.

CLI
Kiro CLI instalado

Instala Kiro CLI, no Kiro IDE. En Windows necesitas Windows 11 y PowerShell; en la página oficial, selecciona la pestaña CLI y el instalador de Windows.

ID
Cuenta de Kiro

Configuración

Conecta Kiro CLI con el chat de PyCharm

Hazlo una sola vez; después podrás elegir Kiro Agent desde AI Chat.

01
Preparación

Instala y autentica Kiro CLI

  1. Abre la página oficial de instalación, cambia de la pestaña IDE a CLI y descarga Kiro CLI para tu sistema. No instales Kiro IDE.
  2. En Windows, instala la versión para Windows 11 y usa PowerShell. Al terminar, abre una ventana nueva y ejecuta kiro-cli --version.
  3. Ejecuta kiro-cli login y completa la autenticación en el navegador si te la solicita.
  4. Comprueba que la instalación esté lista con kiro-cli doctor.
02
Conexión

Agrega Kiro como agente ACP

  1. Cuando AI Assistant esté instalado, abre o vuelve a abrir AI Chat. Si el panel sigue mostrando Install Plugin, completa primero la instalación.
  2. En la esquina superior derecha del panel AI Chat, abre el control para agregar un agente personalizado y elige Add Custom Agent. Si el menú solo muestra Hide y Move to, es el menú general de la ventana; ciérralo.
  3. PyCharm abrirá ~/.jetbrains/acp.json. Agrega la configuración de ejemplo y reemplaza la ruta del comando por la ruta absoluta de Kiro CLI.
  4. Guarda el archivo. En AI Chat, selecciona Kiro Agent.
Configuración ACP

Ejemplo para acp.json

{
  "agent_servers": {
    "Kiro Agent": {
      "command": "C:\\ruta\\completa\\a\\kiro-cli.exe",
      "args": ["acp"]
    }
  }
}
Encuentra la ruta del ejecutable: en Windows, ejecuta Get-Command kiro-cli | Select-Object -ExpandProperty Source en PowerShell. En macOS o Linux, ejecuta which kiro-cli. Copia la ruta devuelta en command; en JSON las barras invertidas de Windows se escriben dobles. Si la opción no aparece, consulta la guía de JetBrains para agregar agentes ACP.

Requerimiento para Kiro

En modulo-01/ejercicios/04_funciones.py agrega una funci?n calcular_progreso(completados, total) que retorne el porcentaje completado como n?mero entre 0 y 100. Si total es 0, debe retornar 0. Agrega ejemplos de uso al final del archivo. No edites otros archivos. Antes de modificar el c?digo, expl?came el plan y espera mi aprobaci?n.   1. 01
    Lee el plan

  2. 02

Errores comunes y cómo reaccionar

Caso 1

`conda` no se reconoce
