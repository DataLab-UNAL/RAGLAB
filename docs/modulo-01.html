Paso 9 · Agentes y modelos de IA

Conecta otros agentes y modelos desde PyCharm

AI Chat permite iniciar agentes integrados, conectar algunos proveedores con tu propia cuenta o clave, y conversar con modelos locales. Las opciones de acceso dependen de cada proveedor.

Agentes integrados

Usa una cuenta o suscripción compatible

  • Codex: puedes autorizarlo con una cuenta de ChatGPT, una clave API de OpenAI o JetBrains AI.
  • Claude Agent: se puede activar con JetBrains AI, una clave API de Anthropic o Anthropic Console.
  • Otros agentes: busca opciones compatibles con ACP en More Agents; cada una tiene su propio proceso de acceso.
Proveedores y modelos

Conecta servicios externos o locales

  • API de terceros: configura OpenAI, Anthropic o un endpoint compatible con OpenAI; Qwen puede usarse si el proveedor ofrece esa API.
  • Modelos locales: conecta Ollama o LM Studio y selecciona un modelo, como Qwen, en AI Chat.
  • Los modelos locales se pueden usar en el chat; la documentación actual indica que no están disponibles para agentes.
Flujo general

Selecciona una opción e inicia su configuración

  1. Abre AI Chat en PyCharm y despliega el selector de agentes o proveedores.
  2. Elige el agente o proveedor. Para algunos agentes, AI Chat abrirá una conversación y deberás enviar un primer mensaje para iniciar la activación.
  3. Sigue el flujo de esa opción: inicia sesión y acepta la instalación del agente, o configura la API key/modelo local en Settings → Tools → AI Assistant → Providers & API keys.
  4. Cuando termine la activación, inicia una conversación nueva si se solicita y selecciona el agente o modelo para usarlo.

Ten en cuenta: pagar una suscripción a un servicio no garantiza que cualquier agente pueda usarla directamente. Revisa el método de acceso que ofrece esa opción; en algunos casos necesitarás JetBrains AI, una API key o una cuenta compatible.

Más información: activar agentes, conectar modelos externos o locales y usar AI Chat.

Paso 10 · Práctica con agentes de IA

Programa con agentes de IA: pide, revisa, ejecuta y valida

Abre modulo-01/ejercicios/04_funciones.py y envía este requerimiento al agente que elegiste:

Requerimiento para el agente

En modulo-01/ejercicios/04_funciones.py, agrega una función llamada calcular_progreso(completados, total) que retorne el porcentaje completado como un número entre 0 y 100. Si total es 0, debe retornar 0. Agrega ejemplos de uso al final del archivo. No edites otros archivos. Antes de cambiar el código, explícame el plan y espera mi aprobación. Después de implementar, dime cómo comprobar los resultados.
  1. 01
    Lee el plan

    Verifica que el agente entendió el archivo, la fórmula y el caso total = 0.

  2. 02
    Inspecciona el diff

    Ubica la función, sus argumentos, el valor que retorna y el caso especial.

  3. 03
    Ejecuta y comprueba

    Verifica que 2 de 4 produzca 50 y que el caso con total 0 produzca 0.

  4. 04
    Guarda cuando lo entiendas

    Si algo falla, comparte el error con el agente. Cuando la mejora funcione, revisa git diff. Puedes pedirle que cree el commit después de revisar los archivos que incluirá. Luego, sube los cambios a GitHub desde la rama DEV.

Pide al agente que prepare el commit

Después de comprobar el resultado y revisar el diff, puedes enviarle una solicitud como esta:

Solicitud para crear el commit

Revisa git status y el diff de los cambios que acabamos de validar. No edites archivos ni incluyas cambios ajenos a este ejercicio. Muéstrame qué archivos vas a incluir y espera mi autorización. Cuando te autorice, crea un commit con el mensaje "Agrega cálculo de progreso". No hagas push.
✓

El agente propone; tú decides. Antes de guardar el cambio, asegúrate de poder explicar qué se modificó y cómo comprobaste que funciona.

Soporte

Si algo se detiene, retoma desde el paso correspondiente

Busca el síntoma y vuelve a la sección indicada. Así podrás resolverlo sin repetir toda la configuración.

Miniconda · Paso 3

conda no se reconoce

En Windows, abre Anaconda Prompt desde Inicio; el instalador recomienda dejar desmarcada la opción para agregar Conda al PATH. En macOS o Linux, abre una terminal nueva después de instalar.

PyCharm · Paso 4

No aparece tu fork al clonar

En Settings → Version Control → GitHub, confirma que PyCharm inició sesión con la cuenta que contiene tu fork de RAGLAB. Luego vuelve a Clone Repository y selecciona ese repositorio.

Entorno · Paso 4

PyCharm no encuentra Python

En la configuración del intérprete, agrega un intérprete Conda existente y selecciona el entorno RAGLAB. Si aún no existe, créalo desde la carpeta raíz con conda env create -f RAGLAB.yml y luego actívalo con conda activate RAGLAB.

Kiro · Paso 8

Kiro no aparece en PyCharm

Confirma que Kiro with GUI figure como instalado en Settings → Plugins → Installed. Reinicia PyCharm y comprueba que el comando del CLI esté configurado en Manage → Settings.

Git · Paso 6

El commit o Push falla

Revisa git status y confirma que estás en la rama DEV. Si Git solicita identidad, configura el nombre y el correo asociados a tu cuenta de GitHub; después vuelve a intentar el commit y git push origin DEV.

Instalación · Pasos 3 y 4

La creación del entorno demora

La primera instalación descarga dependencias como torch y transformers. Mantén abierta la terminal y espera a que termine; si aparece un error, comparte el primer mensaje de fallo antes de volver a ejecutar el comando.

Para pedir ayuda

Comparte el contexto del error

Indica el paso que seguías, qué esperabas que ocurriera y qué ocurrió. Copia el mensaje completo de la terminal o adjunta una captura donde se vea la ventana relevante.
