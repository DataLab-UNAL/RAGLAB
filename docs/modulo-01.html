Programación asistida por agentes

Kiro en PyCharm: del requerimiento al código que podemos validar

Kiro CLI se conecta con PyCharm mediante Agent Client Protocol (ACP). El agente puede leer archivos, proponer cambios y ejecutar comandos; la persona que programa decide qué pedir, revisa los cambios y comprueba el resultado. Este ejercicio usa un script pequeño para practicar el flujo antes de trabajar con proyectos RAG.

Antes de empezar

  • PyCharm 2025.3.2 o posterior y el plugin AI Assistant habilitado para agentes ACP.
  • Kiro CLI instalado. La documentación actual indica Windows 11, macOS o Linux compatible.
  • Una cuenta de Kiro. Al preparar esta guía, el nivel gratuito muestra 50 créditos. El consumo se gestiona en Kiro; las suscripciones de ChatGPT o Claude no lo cubren.

Modelos

Kiro ofrece modelos de Anthropic, OpenAI y modelos de pesos abiertos. El catálogo accesible y el consumo de créditos dependen del plan y pueden cambiar. Para una sesión introductoria, empieza con el modelo recomendado por Kiro (Auto).

Preparación

Instalar y autenticar Kiro CLI

  1. Instala Kiro CLI siguiendo la guía oficial.
  2. En una terminal, ejecuta kiro-cli --version para confirmar la instalación.
  3. Ejecuta kiro-cli login y completa el inicio de sesión en el navegador.
  4. Confirma la sesión con kiro-cli whoami.
Conexión

Agregar Kiro como agente ACP

  1. En PyCharm, abre AI Chat, selecciona la configuración y elige Add Custom Agent.
  2. PyCharm abrirá ~/.jetbrains/acp.json. Agrega la configuración de ejemplo y reemplaza la ruta del comando por la ruta absoluta de Kiro CLI.
  3. Guarda el archivo. En el chat de PyCharm, selecciona Kiro Agent.

Configuración ACP de ejemplo

{
  "agent_servers": {
    "Kiro Agent": {
      "command": "C:\\ruta\\completa\\a\\kiro-cli.exe",
      "args": ["acp"]
    }
  }
}
Encontrar la ruta del ejecutable: en Windows, ejecuta Get-Command kiro-cli | Select-Object -ExpandProperty Source en PowerShell. En macOS o Linux, ejecuta which kiro-cli. Copia la ruta devuelta en command; en JSON las barras invertidas de Windows se escriben dobles. PyCharm requiere AI Assistant compatible con agentes ACP. Consulta la guía de JetBrains para agregar agentes ACP si la opción no aparece.

Práctica: pedir, revisar, ejecutar y validar

Abre modulo-01/ejercicios/04_funciones.py en el proyecto del curso y envía este requerimiento al agente:

Requerimiento para Kiro

En modulo-01/ejercicios/04_funciones.py agrega una función calcular_progreso(completados, total) que retorne el porcentaje completado como número entre 0 y 100. Si total es 0, debe retornar 0. Agrega ejemplos de uso al final del archivo. No edites otros archivos. Antes de modificar el código, explícame el plan y espera mi aprobación. Después de implementar, dime cómo puedo comprobar los resultados.
  1. Lee el plan del agente. Verifica que entendió el archivo, la fórmula y el caso total = 0 antes de aprobarlo.
  2. Inspecciona el diff y localiza la función, sus argumentos, el valor que retorna y el caso especial.
  3. Ejecuta el archivo desde PyCharm. Comprueba que 2 de 4 produce 50 y que el caso con total 0 produce 0.
  4. Si el resultado falla, comparte el error o el resultado inesperado y vuelve a probar.
  5. Cuando entiendas el cambio, revisa git diff y guarda el trabajo con un commit.
Acuerdo de trabajo: el agente propone y modifica; el estudiante conserva la responsabilidad de leer el cambio, ejecutarlo y decidir si cumple el requerimiento. Antes de guardar el cambio, cada estudiante debe poder explicar qué se modificó y cómo comprobó que funciona.

Soporte

Errores comunes y cómo reaccionar

Caso 1

`conda` no se reconoce

Abrir Anaconda Prompt o reiniciar la terminal después de instalar Miniconda.

Caso 2

PyCharm no encuentra el repositorio

Verificar que la conexión con GitHub se hizo sobre la cuenta correcta del estudiante.

Caso 3

PyCharm no encuentra Python

Seleccionar manualmente el intérprete del entorno `RAGLAB`.

Caso 4

El entorno tarda demasiado

Es normal. El archivo del curso instala librerías pesadas como `torch` y `transformers`.
